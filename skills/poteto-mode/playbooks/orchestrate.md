### Orchestrate

In Mistystack, read [the pstack names adapter](../../misty/harnesses/pstack-names.md) once per session before you follow this skill. It maps the Cursor names in pstack skills to your harness.

**Coordinate the program through independent slices and their evidence.** A standing program has several owned outcomes; one task driven to one predicate uses Autonomous run instead.

1. **Scope the program.** Read the native issue and [Misty's briefing contract](../../misty/SKILL.md#briefing-contract). Name the intended user outcome, slice dependencies, owned paths and the exact real-product checks before dispatch.
2. **Assign ownership.** Give each writable branch or shared resource one author. Each slice uses its own snapshot-backed [Boat worker](../../boat-workers/SKILL.md); stop idle workers, resume them for owned work and delete them after their deliverables are retained.
3. **Dispatch independent slices together.** Give every worker the raw inputs, complete path contract, dependencies and outside check it needs. Bound the scope by the user's outcome, not a fixed agent count, nesting depth, elapsed time or turn allowance.
4. **Deliver through one method.** Each author follows the installed [ship-loop](../../ship-loop/SKILL.md) skill. Inspect the delivered artifact and running-path evidence rather than accepting a worker's summary or adding a verifier, judge or PR gate.
5. **Keep native state.** Use the issue, owned branches and retained evidence so a replacement can recover the work. Check a PR, release or deployment's actual state before reporting it. Keep work outside the program in its owned backlog, not a fix ledger.
6. **Supervise until completion.** Use the installed [watchdog](../../watchdog/SKILL.md) to inspect concrete side effects and recover errors, stalls or lost workers. Reconcile a late result against the current owned artifact. Work stays open-ended while actionable work remains; a timer or retry count does not abandon a slice.
7. **Respect an explicit hold.** Send a stop or zero-writes order to each affected owner. Preserve its branch, evidence and resource identity for resumption. Ask the owner only for an unresolved product choice, irreversible action or unreachable prerequisite.

**Reply:** the consumer outcome, each slice's observed state and links, what merged and released, running-path evidence, resources cleaned up and any exact remaining blocker.
