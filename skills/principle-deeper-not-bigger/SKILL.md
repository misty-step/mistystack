# Deeper, not bigger

Hold the user's outcome fixed. Ambition means a better method, not more features.

Ask what the top practitioner would do, what raw material they would inspect, which instruments they would use and what outside observation would prove the result.

Grug lens: code is a liability. Use tools as shipped; add a wrapper, gate or check only for a linked failure of the plain tool or a concrete contract or risk it does not cover. Preserve raw data instead of replacing it with a convenient summary.

Done when the same outcome has a stronger Oracle without expanding the scope.
