# 3. Shape

Use pstack's [Prototype](../../skills/poteto-mode/playbooks/prototype.md) to settle an empirical question with a throwaway sketch. Use [multi-phase-plan](../../skills/poteto-mode/playbooks/multi-phase-plan.md) for phases or stacked PRs, [figure-it-out](../../skills/figure-it-out/SKILL.md) for an open-ended problem, and [orchestrate](../../skills/poteto-mode/playbooks/orchestrate.md) for a standing project.

Keep the complete outcome in view. [Foundation article 3](../../skills/foundation/checklist.md#article-3) requires a living `SPEC.md`, not a particular skill for producing it. The [initiative story](../../USER_STORIES.md#us-053-lead-full-value-initiatives-through-atomic-delivery) owns slice acceptance.

Use [research](../../skills/research/SKILL.md) for unfamiliar contracts and [design](../../skills/design/SKILL.md) for interfaces. Apply [unslop](../../skills/unslop/SKILL.md), [technical-writing](../../skills/technical-writing/SKILL.md) and pstack's [Writing the reply](../../skills/poteto-mode/SKILL.md#writing-the-reply) to prose. Use [agent-design](../../skills/agent-design/SKILL.md) when the deliverable instructs agents.
