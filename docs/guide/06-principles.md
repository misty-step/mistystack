# 6. Principles

[Misty's principles](../../skills/misty/principles.md) are one short file. Each entry names the moment it applies and the reason behind it. They describe taste, so an agent reads the entry that matches what it is doing and is not asked to cite them.

The [core](../../rules/core.md) owns the standing rules. [Verification](../../skills/verification/SKILL.md), [ship-loop](../../skills/ship-loop/SKILL.md), [agent-design](../../skills/agent-design/SKILL.md), [watchdog](../../skills/watchdog/SKILL.md) and [release-watch](../../skills/release-watch/SKILL.md) own their task procedures.

The [Foundation checklist](../../skills/foundation/checklist.md) serves a different purpose: it states what every project must have. The [audit skill](../../skills/foundation/SKILL.md) checks each article against the real project. Recorded deviations are decisions in that repository; unknown evidence remains unverified.

Use those homes rather than copying rules into project instructions. A project adds only its local constraints and pointers.
